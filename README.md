# 框一下｜教學截圖工具

繁體中文的截圖標註網頁。圖片只在瀏覽器中處理，不會上傳至伺服器。

## 功能

- 開啟、拖曳或貼上 PNG、JPG、WebP、GIF 圖片
- 紅框、箭頭、步驟編號、說明文字與馬賽克
- 拖曳移動與調整標註大小，修改顏色與線條粗細
- 復原、重做、縮放，以及原始解析度 PNG 匯出
- 範例圖片與手機版介面

## 本機使用

以瀏覽器開啟 `dist/index.html` 即可使用，不需要安裝套件。

也可以安裝 Node.js 後，在專案目錄執行：

```sh
node preview.cjs
```

然後開啟 http://127.0.0.1:4173 。

## 操作方式

1. 開啟圖片，或點「先用範例試試看」。
2. 選擇紅框、箭頭或馬賽克後，在圖片上拖曳；編號與文字則點一下放置。
3. 使用選取工具移動標註，拖曳右下角控制點調整大小。
4. 點「下載 PNG」儲存成品。重新整理或更換圖片前，請先下載需要保留的圖片。

快捷鍵：`V` 選取、`R` 紅框、`A` 箭頭、`N` 編號、`T` 文字、`M` 馬賽克；`Ctrl/⌘ + Z` 復原，`Ctrl/⌘ + Shift + Z` 重做。

## 檔案

- `dist/`：可直接部署的靜態網站
- `preview.cjs`：本機預覽伺服器
- `qa.cjs`：開發環境使用的 Playwright 檢查脚本；套件與瀏覽器路徑需依環境調整
- `.openai/hosting.json`：原 Sites 網站的部署設定

GIF 以靜態圖片處理。標註目前保存在頁面記憶體中，不會自動保存。馬賽克匯出前請確認遮蔽效果。
