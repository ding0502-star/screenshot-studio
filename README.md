# 框一下｜多頁教學截圖編輯器

直接使用：https://ding0502-star.github.io/screenshot-studio/

繁體中文、免登入的教學截圖工具。圖片與 OCR 均在瀏覽器內處理，不會上傳到伺服器。

## 教學製作流程

1. 開啟圖片，用「新增頁面」或「匯入多圖」建立多頁教學。每頁原圖和標註各自保留，可改標題、排序、替換圖片或刪頁。
2. 用紅框、箭頭、編號、文字、步驟框、螢光筆、聚光燈與局部放大標示重點。
3. 使用「圖左文右」或「上圖下文」排列步驟框，也能設定四邊留白、配色或自訂樣式。
4. 下載本頁 PNG、複製本頁圖片，或匯出整份教學為長圖 PNG／A4 PDF。長截圖 PDF 會自動分頁。
5. 下載專案 JSON 可在其他裝置繼續編輯。支援舊版單頁專案。

## 文件製作與維護（第 6 版）

- 預設「簡易模式」提供紅框、箭頭、遮蔽與步驟框；切換「進階模式」可使用全部工具，選擇會記住。
- 「替換圖片」可保留標註並按新尺寸縮放、保留座標，或清除標註。版面不同仍需手動檢查。替換及刪頁前會先建立可還原的歷史版本。
- 「歷史版本」在此瀏覽器保留最近 10 份快照，總量約 80 MB；支援手動命名、還原與還原前備份。一般編輯靜止後保存，頻率最多每分鐘一次。瀏覽器儲存失敗時不會執行需要備份的換圖、刪頁或還原；可先下載 JSON 專案。
- 多選一支箭頭與一個說明框、文字或放大框後，按「連動箭頭」。起點會跟隨說明框，尖端維持指向原圖位置；解除連動即可自由移動。
- 常用說明可一鍵放入步驟框，支援保存 20 條自訂文字。「注意、完成、必填、不需填寫」圖章可改字、調色與縮放。
- 匯出 PNG、剪貼簿、長圖或 PDF 前，檢查標註超界、說明文字重疊、文字過小與重複編號。可定位修改或仍要匯出；不會檢查原圖內容。
- 「封面、頁首頁尾與 Logo」可設定標題、單位、日期、版本、Logo。PDF、長圖與閱讀模式套用設定；本頁 PNG 維持原始畫面。
- 「閱讀教學」依各頁步驟順序展示，支援上一／下一步與左右方向鍵；不會變更編輯頁或標註。此模式在目前瀏覽器閱讀，對外分享請匯出 PDF／PNG。

## 編輯與步驟管理

- 右側清單顯示本頁標註，可拖曳或以前移／後移排序。「本頁步驟自動編號」開啟後，新增、移除和排序會重編號；關閉後可自行修改編號。
- Shift 點選多選；可複製、鎖定／解鎖、靠左／靠右／靠上／靠下／置中、垂直等距排列。
- 鎖定標註不接受移動、文字與樣式編輯；仍可從清單選取解鎖。裁切與版面留白屬整頁變更。
- 裁切保留原圖，可復原或還原原圖。局部放大不會重新顯示已被實心遮蔽的原圖內容。
- 快捷鍵：V 選取、R 紅框、A 箭頭、N 編號、T 文字、S 步驟框、M 馬賽克、B 實心遮蔽、H 螢光筆、C 裁切、Z 局部放大。
- Ctrl/⌘+Z 復原，Ctrl/⌘+Shift+Z 重做，Ctrl/⌘+D 複製，Ctrl/⌘+A 多選；方向鍵微調，Shift+方向鍵移動 10 px。

## 自動儲存與隱私

草稿自動儲存於目前瀏覽器的 IndexedDB，重新開啟會提供恢復／捨棄選項。未恢復的舊草稿不會被新編輯覆蓋。瀏覽器清除資料、私密瀏覽或儲存空間不足可能影響草稿；重要內容請另存專案。

專案、草稿及歷史版本包含未遮蔽原圖。分享教學請使用 PNG 或 PDF。

## OCR 與個資建議

支援繁體中文＋英文或英文／數字。辨識使用本機 Tesseract.js；模型與引擎從本網站載入，圖片不會送出。Email、台灣電話、身分證格式與長串數字以規則比對提出建議，使用者勾選後才會新增實心遮蔽。OCR 可能誤判或漏判，姓名、地址及其他個資須人工檢查。可編輯／複製辨識文字或將其放入說明。

## 限制

- PNG、JPG、WebP、GIF；GIF 以靜態圖片處理。單張檔案上限 30 MB，單頁上限 3200 萬像素、任一邊 16000 px。
- 一份教學最多 30 頁、原圖合計 1 億像素；單次多圖匯入最多 20 張。
- 長圖匯出上限 3200 萬像素、高 16000 px；更長教學請用 PDF。
- 剪貼簿需 HTTPS 或 localhost 及瀏覽器允許。草稿按瀏覽器與網站來源分開保存。
- 合併視窗的「加入目前成品」會產生已合成的新頁；原本頁面的可編輯標註仍保留。

## 本機開發

安裝 Node.js 後執行 node preview.cjs，開啟 http://127.0.0.1:4173 。建議透過本機伺服器使用完整功能，OCR Worker 無法直接用 file:// 執行。

dist/ 為可部署靜態網站；app.js 保留基本標註工具，studio.js 提供多頁／草稿／OCR／匯出與進階編輯。plus.js 提供模式、版本、連動、換圖、文件設定、檢查與閱讀。dist/vendor/ 隨附 Tesseract.js 7、OCR 引擎與語言資料、pdf-lib，以及各自授權檔。

## 驗證

qa-studio.cjs、qa-studio-edge.cjs 檢查多頁編輯、草稿往返、真實英文與繁中 OCR、遮蔽與放大、PDF 分頁及行動版。qa-plus.cjs 驗證本版八項擴充、版本還原、Logo 專案往返與三頁 PDF；其餘 qa-*.cjs 涵蓋原有功能；Playwright 與 Edge 路徑請依測試環境調整。

## 第 7 版：教材管理與分享

- **我的教材**：以縮圖管理獨立教材，支援搜尋、改名、複製、開啟及刪除。編輯後會自動保存；切換前先保存目前教材，儲存失敗則不切換。刪除正在編輯的教材會同步清空編輯畫面及其草稿。
- **跨頁複製**：進階模式多選標註，按「複製到其他頁」。可勾選多個目標頁並選擇是否按尺寸縮放；複製的連動箭頭會指向同組新標註。各頁可獨立修改／復原。遮蔽與放大取樣區需確認適合新頁。
- **對齊吸附**：拖曳時顯示邊緣／中心輔助線，對齊其他標註或畫布；可取消勾選，或按 Alt 暫停。
- **整份教學編號**：進階模式右側選擇「每頁重新編號」「整份教學連續編號」或「手動編號」，新增、複製與頁面排序後重新計算。
- **互動 HTML**：從「匯出整份教學」下載，可離線開啟、使用上一／下一步及方向鍵。包含已合成圖片與步驟文字，不攜帶可編輯原圖；與遮蔽重疊的步驟文字不另行輸出。此功能產生檔案，不會自動公開上網。
- **A4 列印預覽／分頁**：預覽與 PDF 使用同一套分頁與排版；自動分頁避開能在單頁容納的文字、步驟、編號及放大框。可按原圖 Y 座標指定分頁位置，或恢復自動分頁。過高標註／手動切點仍可能切過標註，預覽會提示。
- **我的教材範本**：保存封面、Logo、配色、留白、目前說明及常用文字（最多 20 個範本），供新教材套用。套用前建立歷史版本；不會把截圖存入範本。
- **換圖前後比較**：選擇替換圖片後並排顯示現有成品與新圖預覽；切換保留方式會更新預覽，確認套用前不修改原教材。
- **觸控**：雙指縮放與平移；第二指加入時會取消第一指誤畫的內容。提供較大的縮放控制點及「平移」按鈕；單指仍可標註。

教材庫、範本、草稿及歷史版本都保存在目前瀏覽器，沒有雲端同步。重要教材請下載 JSON 專案備份；對外分享使用 PDF、PNG 或互動 HTML。

workflow.js 提供上述功能。qa-workflow.cjs、qa-workflow-touch.cjs、qa-workflow-library.cjs 分別涵蓋製作／分享、實際雙指事件、儲存失敗與刪除保護。
